# Pharmacy Management System (PHP OOP)

A simple, web-based inventory system designed to manage medicine records. This project demonstrates the core principles of Object-Oriented Programming (OOP) in PHP, including inheritance and encapsulation.

## 🚀 Features
* **OOP Structure:** Uses a parent `Product` class and a child `Medicine` class.
* **Dynamic Data:** Stores medicine objects in a session-based array during runtime.
* **Clean UI:** Simple, responsive interface built with HTML and CSS.
* **Real-time Updates:** Add records and see them displayed immediately in a formatted table.

## 🛠️ Tech Stack
* **Language:** PHP 8.x
* **Frontend:** HTML5, CSS3
* **Concepts:** Encapsulation, Constructors, Inheritance, Session Management.

## ⚙️ Setup Instructions
1. Clone this repository to your local server directory (e.g., `htdocs` for XAMPP).
2. Start your Apache server via the XAMPP Control Panel.
3. Open your browser and navigate to `http://localhost/pharmacy/`.
4. Add medicine details via the form to populate the table.

## 📂 Logic Overview
The system uses a parent class to handle general product attributes and a child class for medicine-specific data.
